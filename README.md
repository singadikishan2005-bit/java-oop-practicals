# Java OOP Lab — VTU Coursework

Java Object-Oriented Programming lab exercises from the B.E. AI & Data Science program at SJCIT (VTU).

## Topics Covered

- Classes and Objects
- Inheritance (Single, Multi-level, Hierarchical)
- Polymorphism (Method Overloading and Overriding)
- Encapsulation and Abstraction
- Interfaces and Abstract Classes
- Exception Handling
- Collections Framework (ArrayList, HashMap, LinkedList)
- File I/O
- Threads and Concurrency Basics
